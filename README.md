# りんの大冒険

りんが主人公の横スクロールアクションゲーム（PWA）。
iPhone の横画面で、左右ボタン＋ジャンプボタンで遊べます。ビルド不要（HTML / CSS / JavaScript だけ）。

## 遊び方

| 操作 | タッチ | キーボード |
| --- | --- | --- |
| 左右に歩く | ◀ ▶ ボタン（指をすべらせて切りかえOK） | ← → / A D |
| ジャンプ | ジャンプボタン（長く押すほど高く飛ぶ） | Space / ↑ / W / Z |
| ポーズ | 右上の II ボタン | Esc / P |

- 歩き続けると少しずつ速くなり、走りジャンプは遠くまで飛べます
- 敵は上から踏むと倒せます（トゲぼう・ウニ・ゴロいわは踏めません）
- ？ブロックからは、コイン・金のリンゴ（パワーアップ）・にじ色スター（無敵）・ハート／豚まん（1UP）が出ます
- 各ステージに「ひみつのメダル」が3枚かくれています
- 進みぐあい（クリアしたステージ・メダル）はその端末に自動保存されます

## GitHub Pages で公開する手順（はじめの1回）

1. GitHub Desktop で「File → Add Local Repository」からこのフォルダ（rin-adventure）を選ぶ
   - 「create a repository」と出たら、そのまま作成する
2. 変更をコミット → 「Publish repository」
   - 「Keep this code private」のチェックを外す（無料プランで GitHub Pages を使うため public にする）
3. GitHub のリポジトリページ → Settings → Pages
   - Source：Deploy from a branch
   - Branch：main / (root) → Save
4. 数分待つと公開されます
   - URL：`https://ykyuki1991.github.io/rin-adventure/`

## iPhone に入れる（甥っ子さんの端末）

1. iPhone の Safari で公開 URL を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、アドレスバーなしの全画面で遊べます
   - 一度開けば、オフラインでも遊べます
   - 音が出ないときは、iPhone の消音（マナーモード）をオフにしてください

## ダブルタップで拡大・縮小されてしまう問題の対策

以下を組み合わせて、ブラウザ側の拡大・縮小やスクロールを止めています。

- `index.html`：viewport で拡大禁止（`user-scalable=no` など）
- `css/style.css`：`touch-action: none`（ダブルタップズーム・ピンチ・スクロールを無効化）、文字選択・長押しメニューの無効化
- `js/input.js`：`touchstart / touchmove / touchend` と iOS 独自の `gesturestart` などを `preventDefault()`
- ボタンはすべて pointer イベントで反応させているので、上の対策をしても操作できます

## 更新するとき

1. ファイルを修正 → GitHub Desktop でコミット → 「Push origin」（GitHub Pages に自動で反映）
2. ファイルを追加したら `sw.js` の `ASSETS` に追加し、`VERSION` の数字を上げる
   - ネットにつながっていれば、次に開いたときに最新版になります

## 手元（Mac）で動かす

ES Modules を使っているため、ファイルをダブルクリックで開く（file://）と動きません。簡易サーバーで開いてください。

```sh
cd rin-adventure
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

VS Code の拡張機能「Live Server」でも OK です。

開発用の URL パラメータ

- `?stage=2`：ステージ2からすぐ始める（1〜10）
- `?debug`：当たり判定の枠とかくしブロックを表示

## ファイル構成

```
index.html            画面の骨組み（メニュー・ボタン）
manifest.webmanifest  PWA の設定（アプリ名・アイコン・横向き）
sw.js                 オフライン対応（Service Worker）
css/style.css         メニューやボタンの見た目
icons/                アプリのアイコン
js/main.js            全体のまとめ役（画面切りかえ・ゲームループ）
js/game.js            ゲームの進行（当たり判定・ブロック・ゴール・ボス）
js/player.js          りんの動き
js/entities.js        敵・アイテム・動く足場など
js/levels.js          ステージデータ（ここを書きかえるとステージが変わる）
js/level.js           ステージを作るための道具（LevelBuilder）
js/physics.js         タイル・坂道との当たり判定
js/zones.js           滝・風・シャワーの力
js/render.js          描画の順番・カメラ・HUD
js/themes.js          場所ごとの色と背景（六甲山・ポートタワー・明石海峡大橋など）
js/tiles.js           タイルの絵（レンガ・うろこ壁・コンテナ・橋など）
js/decos.js           看板・建物・乗り物などの飾り
js/sprites.js         キャラクター・敵・アイテムの絵
js/audio.js           効果音と BGM（音声ファイルなし、その場で合成）
js/input.js           タッチ・キーボード操作、ズーム防止
js/storage.js         進みぐあいの保存
js/config.js          ジャンプの高さや速さなどの数値
```

## ステージの作り方（js/levels.js）

座標はマス単位です（x：左から何マス目、y：上から何マス目。画面は縦15マス）。

```js
b.theme(120, 'nankin');                       // x=120 から南京町の見た目に切りかえ
b.ground(0, 30, 13);                          // x=0〜30 に地面（表面の高さ y=13）
b.row(12, 9, '?BPB?');                        // x=12 から横に並べる（1文字 = 1マス）
b.rampUp(40, 13, 4, true);                    // ゆるい上り坂
b.mat('wood', () => b.row(50, 9, '===='));    // 木の足場（mat で見た目を変える）
b.train(60, 12, 20, { look: 'train' });       // 往復する電車
b.ropeway(14, 12, 60, 9, 4, 42);              // ロープウェイ（ゴンドラ4台）
b.wheel(90, 6, 4, 6, 0.3);                    // 観覧車
b.zone('fall', 100, 0, 3, 13);                // 滝（下向きの流れ）/ spray / wind
b.sign(8, '八雲通', 'やくもどおり', 13, 'station'); // 看板
b.enemy('slime', 17);                         // 敵（slime / spiky / bird / frog / rock / crab / boss）
b.medal(86, 4);                               // ひみつのメダル
b.checkpoint(111);                            // 中間ポイント
b.goal(180, 13);                              // ゴール
```

`row` で使える文字：G 地面 / X かたいブロック / B レンガ / K コインがたくさん出るレンガ / ? コイン / P パワーアップ / S スター / L 1UP / H かくし1UP / h かくしコイン / = すり抜け足場 / - 見えないすり抜け足場（飾りの上に立つ用） / # 見えないかべ / ^ トゲ / ~ マグマ / w 水 / / \ 坂（1 2 3 4 はゆるい坂） / Z ニセブロック / o コイン / M メダル
