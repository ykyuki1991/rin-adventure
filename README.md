# りんの大冒険

りんが主人公の横スクロールアクションゲーム（PWA）。
iPhone の横画面で、左右ボタン＋ジャンプボタンで遊べます。ビルド不要（HTML / CSS / JavaScript だけ）。

## 遊び方

| 操作 | タッチ | キーボード |
| --- | --- | --- |
| 左右に歩く | ◀ ▶ ボタン（指をすべらせて切りかえOK） | ← → / A D |
| ジャンプ | ジャンプボタン（長く押すほど高く飛ぶ） | Space / ↑ / W / Z |
| ポーズ | 右上の II ボタン | Esc / P |

- 歩き続けると少しずつ速くなり、走りジャンプは遠くまで飛べます
- 敵は上から踏むと倒せます（トゲぼう・ウニ・ゴロいわ・クラゲは踏めません）
- 場所ごとの敵：イノシシ（近づくと突進）・ペンギン（おなかですべる）・クラゲ（上下にふわふわ）・ちょうちんおばけ（そっと近づく）・タコ（海からとび出す）
- ？ブロックからは、コイン・金のリンゴ（パワーアップ）・にじ色スター（無敵）・ジャンプぐつ（高くとべて空中でもう1回ジャンプ・20秒）・1UP が出ます
- 1UP は場所によって見た目が変わります（ハート・豚まん・神戸プリン・明石焼き）
- 敵をやっつけるとコインがもらえます（100枚で1UP）。続けてふむと点数と音が上がります
- 各ステージに中間ポイントがあり（後半のステージは2か所）、ミスしてもそこから再開できます。ゲームオーバーのあとも中間ポイントから続けられます
- 同じところで3回続けてミスすると「おたすけ」で金のリンゴを持ってスタートします
- ステージ1や、はじめて出てくるしかけの前には、ふきだしのヒントがあります
- 各ステージに「ひみつのメダル」が3枚かくれています。一度クリアすると、ステージ選択の画面にまだ取っていないメダルのヒントとベストタイムが出ます
- 進みぐあい（クリアしたステージ・メダル）はその端末に自動保存されます

## GitHub Pages で公開する手順（はじめの1回）

1. GitHub Desktop で「File → Add Local Repository」からこのフォルダ（rin-adventure）を選ぶ
   - 「create a repository」と出たら、そのまま作成する
2. 変更をコミット → 「Publish repository」
   - 「Keep this code private」のチェックを外す（無料プランで GitHub Pages を使うため public にする）
3. GitHub のリポジトリページ → Settings → Pages
   - Source：Deploy from a branch
   - Branch：main / (root) → Save
4. 数分待つと公開されます
   - URL：`https://ykyuki1991.github.io/rin-adventure/`

## iPhone に入れる（甥っ子さんの端末）

1. iPhone の Safari で公開 URL を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、アドレスバーなしの全画面で遊べます
   - 一度開けば、オフラインでも遊べます
   - 音が出ないときは、iPhone の消音（マナーモード）をオフにしてください

## ダブルタップで拡大・縮小されてしまう問題の対策

以下を組み合わせて、ブラウザ側の拡大・縮小やスクロールを止めています。

- `index.html`：viewport で拡大禁止（`user-scalable=no` など）
- `css/style.css`：`touch-action: none`（ダブルタップズーム・ピンチ・スクロールを無効化）、文字選択・長押しメニューの無効化
- `js/input.js`：`touchstart / touchmove / touchend` と iOS 独自の `gesturestart` などを `preventDefault()`
- ボタンはすべて pointer イベントで反応させているので、上の対策をしても操作できます

## 更新するとき

1. ファイルを修正 → GitHub Desktop でコミット → 「Push origin」（GitHub Pages に自動で反映）
2. ファイルを追加したら `sw.js` の `ASSETS` に追加し、`VERSION` の数字を上げる
   - ネットにつながっていれば、次に開いたときに最新版になります

## 手元（Mac）で動かす

ES Modules を使っているため、ファイルをダブルクリックで開く（file://）と動きません。簡易サーバーで開いてください。

```sh
cd rin-adventure
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

VS Code の拡張機能「Live Server」でも OK です。

開発用の URL パラメータ

- `?stage=2`：ステージ2からすぐ始める（1〜10）
- `?debug`：当たり判定の枠とかくしブロックを表示

## ステージの作り方（js/levels.js）

座標はマス単位です（x：左から何マス目、y：上から何マス目。画面は縦15マス）。

```js
b.theme(120, 'nankin');                       // x=120 から南京町の見た目に切りかえ
b.ground(0, 30, 13);                          // x=0〜30 に地面（表面の高さ y=13）
b.row(12, 9, '?BPB?');                        // x=12 から横に並べる（1文字 = 1マス）
b.rampUp(40, 13, 4, true);                    // ゆるい上り坂
b.mat('wood', () => b.row(50, 9, '===='));    // 木の足場（mat で見た目を変える）
b.train(60, 12, 20, { look: 'train' });       // 往復する電車
b.ropeway(14, 12, 60, 9, 4, 42);              // ロープウェイ（ゴンドラ4台）
b.wheel(90, 6, 4, 6, 0.3);                    // 観覧車
b.zone('fall', 100, 0, 3, 13);                // 滝（下向きの流れ）/ spray / wind
b.sign(8, '八雲通', 'やくもどおり', 13, 'station'); // 看板
b.enemy('slime', 17);                         // 敵（slime / spiky / bird / frog / rock / crab / boar / penguin / lantern / boss）
b.enemy('jelly', 45, 13, { range: 2 });       // クラゲ（range マスぶん上下する）
b.enemy('tako', 101, 13, { height: 7 });      // タコ（水の中から height マスとび出す）
b.medal(86, 4, '観覧車のまん中');             // ひみつのメダル（3つ目はステージ選択に出るヒント）
b.hint(6, 7, '？ブロックを 下からたたこう');  // ふきだしのヒント
b.coinArc(18, 24, 11, 2);                     // コインを山なりに並べる（かべの中には置かない）
b.coinLine(20, 9, 56, 6, 4);                  // コインを線の上に並べる
b.coinsAbove(88, 152, 5);                     // 足場のすぐ上にコインを並べる
b.checkpoint(111);                            // 中間ポイント
b.goal(180, 13);                              // ゴール
```

`row` で使える文字：G 地面 / X かたいブロック / B レンガ / K コインがたくさん出るレンガ / ? コイン / P パワーアップ / S スター / J ジャンプぐつ / L 1UP / H かくし1UP / h かくしコイン / = すり抜け足場 / - 見えないすり抜け足場（飾りの上に立つ用） / # 見えないかべ / ^ トゲ / ~ マグマ / w 水 / / \ 坂（1 2 3 4 はゆるい坂） / Z ニセブロック / o コイン / M メダル

## 絵（デザイン）の仕組み

キャラクター・敵・アイテム・地形・背景の絵は、SVG（ベクター形式）で描いて `art/` に置いてあります。
ゲームは起動したときに、画面の細かさに合わせてこの SVG を一度だけ画像にして使うので、iPhone の高精細な画面でもくっきり表示されます。

- `art/chars.svg` りん（立ち・走り4コマ・ジャンプ・落下・のぼり・やられ・マントつき・ジャンプぐつの羽）
- `art/enemies.svg` スライム・トゲぼう・ウニ・カニ・鳥・ハチ・コウモリ・カエル・ゴロいわ・イノシシ・ペンギン・クラゲ・ちょうちんおばけ・タコ・キングスライム
- `art/items.svg` コイン・メダル・金のリンゴ・スター・ジャンプぐつ・ハート・豚まん・神戸プリン・明石焼き・ブロック・旗
- `art/tiles.svg` 地形タイル（全15か所ぶん：石垣・石だたみ・岸壁・レンガ・草と土・砂浜・岩・橋のトラス・ケーブル・生け垣・温室のガラス・ビル・水など）
- `art/decos.svg` `art/decos2.svg` `art/pf.svg` 家・店・駅・門・屋台・海の家・移情閣・動物・新幹線・ポートタワー・電車・船・ゴンドラ・キリン・シャチ・浮き輪など
- `art/bg/*.svg` 背景（場所ごとに奥から手前へ何枚も重ねる）

全10ステージ・15か所の地形と背景が、同じ画風の SVG の絵になっています（SVG がない絵は自動でこれまでのプログラムの絵になります）。

### 絵を直すとき

1. SVG は `tools/art/` の中のプログラム（chars.mjs・enemies.mjs・enemies2.mjs・items.mjs・tiles.mjs・tiles2.mjs・decos.mjs・decos2.mjs・bgs.mjs・bgs2.mjs・yakumo.mjs・yakumo2.mjs）から作っています。ステージ1（八雲通・春日野道）の背景・地面は yakumo.mjs、店・アーケード・街灯・家などの飾りは yakumo2.mjs です
2. 直したら、次のコマンドで `art/*.svg` と `js/art-data.js` を作り直す（`sw.js` のファイル一覧も自動で直ります）

```sh
node tools/art/build.mjs
```

- 書き出した `art/*.svg` は Penpot や Inkscape でそのまま開いて確認・修正できます（ただし上のコマンドを実行すると上書きされます）
- `node tools/art/preview.mjs 出力.png 8 "#dfe6ee" rin/` のようにすると、絵を大きくして並べた確認用の画像を作れます（sharp が必要）
